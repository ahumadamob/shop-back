# Shop Backend

This project exposes a set of REST endpoints documented with Swagger UI.

Once the application is running, open your browser and navigate to:

```
http://localhost:8080/swagger-ui/index.html
```

This page renders the interactive API documentation generated by `springdoc-openapi`.

The application uses an in-memory H2 database by default. You can access the H2 console at:

```
http://localhost:8080/h2-console
```
